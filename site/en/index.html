What it is for

Claude's built-in web tools fall short in many real cases. Web Research Pro gives Claude a set of local scripts that read the web the way a careful person would.

JavaScript pages come back empty

Real browser (Chromium)

Opens apps, dashboards and shops in a real browser and waits until they finish rendering.

The site blocks automated requests (403)

Automatic fallback ladder

Tries a browser, a reader service and the Wayback Machine copy. No CAPTCHA solving.

WebFetch returns a summary, so figures and tables get lost

Full text as Markdown

Keeps tables, links and code blocks, with a header saying exactly how the content was obtained.

Compressed PDFs cannot be read

PDFs, RSS/Atom and JSON

Extracts the text of every page of a PDF, with page markers so you can cite it.

The content is behind your login

Your own sessions

You sign in yourself in a real window; the session stays on your machine and your password never goes through Claude.

You need many pages, or to track a price

Crawling, monitoring and search

Saves whole site sections, tells you when something changes and searches by region on DuckDuckGo, GitHub, arXiv, Reddit and more.

How it works

It only climbs a rung when needed, so the usual case is fast (under a second).

  1. HTTP

    A request with browser headers. Handles articles, docs, PDFs, feeds and APIs.

  2. Browser

    Real Chromium when the page is a JavaScript shell or hits an anti-bot wall.

  3. Reader

    The r.jina.ai service turns the page into Markdown from its own servers.

  4. Archive

    The Wayback Machine copy, always labelled with its date.

With your session, or on private addresses (intranet, localhost), it never uses third-party services.

Install

Requires Python 3.9+ and Claude Code. The installer creates a private environment in ~/.web-research-pro and downloads Chromium once (about 200 MB).

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/mohaaa012/web-research-pro/main/install.sh | bash

Windows (PowerShell)

irm https://raw.githubusercontent.com/mohaaa012/web-research-pro/main/install.ps1 | iex

As a Claude Code plugin

claude plugin marketplace add mohaaa012/web-research-pro
claude plugin install web-research-pro@mohaaa012-plugins

Then restart Claude Code and just talk to it: "Read this PDF and give me the key figures", "Watch this page and tell me if the price drops below €150". For claude.ai, download the .skill file from Releases.

What it does not do (and why)

Honesty is part of the design.

  • No CAPTCHA solving or anti-bot evasion. It looks for legitimate routes instead: public APIs, RSS, archived copies or other sources.
  • No paywall bypassing. It finds the information in open sources and tells you the original was paywalled.
  • No access to other people's accounts. Only yours, with your permission.
  • No aggressive crawling. It obeys robots.txt, waits between requests and has a page limit.

FAQ

Is it an alternative to Claude's WebFetch and WebSearch?

Yes. WebFetch hands the page to a small model and returns its summary; it cannot run JavaScript or log in. Web Research Pro returns the full text, uses a real browser when needed and searches by region. For a quick lookup, WebSearch is still fine; Claude picks the cheaper option each time.

How do I make Claude read JavaScript-rendered pages?

Install the skill and give Claude the URL. If the plain response comes back empty, the skill opens the page in Chromium, waits for it to render and returns the text as Markdown.

Can Claude read a long PDF in full?

Yes. fetch.py extracts the text of every page, with page markers for citing. In the benchmark, a 14-page PDF was read in full in 1.3 seconds.

Can I use it for web scraping with Claude Code?

Yes, politely: crawl.py saves a whole site section as Markdown files, obeys robots.txt, waits between requests and removes duplicates. It is not meant to get around protections.

Does it work on claude.ai or Claude Desktop?

You can upload the .skill file in Settings → Capabilities → Skills, but that environment may have no browser or open internet access. The full experience is in Claude Code.

How much does it cost?

Nothing. It is open source under the MIT license. Search keys (Brave, Tavily, SearXNG) are optional and all have free tiers.
