Web Research Pro: el skill de Claude Code para investigar en internet de verdad.

¿Para qué sirve?

Las herramientas web que trae Claude se quedan cortas en muchos casos reales. Web Research Pro les da a Claude unos scripts locales que leen la web como lo haría una persona cuidadosa.

Las páginas hechas con JavaScript llegan vacías

Navegador real (Chromium)

Abre apps, paneles y tiendas en un navegador de verdad y espera a que terminen de pintarse.

La web bloquea las peticiones automáticas (403)

Escalera automática

Prueba navegador, servicio lector y copia archivada en Wayback Machine. Sin saltarse CAPTCHAs.

WebFetch devuelve un resumen y se pierden cifras y tablas

Texto completo en Markdown

Conserva tablas, enlaces y bloques de código, con una cabecera que dice cómo se obtuvo.

Los PDF comprimidos no se pueden leer

PDFs, RSS/Atom y JSON

Extrae el texto de todas las páginas de un PDF, con marcas de página para poder citar.

El contenido está detrás de tu login

Tus propias sesiones

Inicias sesión tú en una ventana real; se guarda solo en tu ordenador y la contraseña nunca pasa por Claude.

Hay que leer muchas páginas o seguir un precio

Rastreo, vigilancia y búsqueda

Guarda secciones enteras, avisa cuando algo cambia y busca por región en DuckDuckGo, GitHub, arXiv, Reddit y más.

Cómo funciona

Solo sube de escalón cuando hace falta, así que lo normal es rápido (menos de un segundo).

  1. HTTP

    Petición con cabeceras de navegador. Resuelve artículos, documentación, PDFs, feeds y APIs.

  2. Navegador

    Chromium real cuando la página es una cáscara de JavaScript o hay un muro anti-bots.

  3. Lector

    El servicio r.jina.ai convierte la página en Markdown desde sus servidores.

  4. Archivo

    La copia de Wayback Machine, siempre marcada con su fecha.

Con tu sesión o en direcciones privadas (intranet, localhost) nunca usa servicios de terceros.

Instalación

Necesitas Python 3.9 o superior y Claude Code. El instalador crea un entorno privado en ~/.web-research-pro y descarga Chromium una sola vez (unos 200 MB).

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/mohaaa012/web-research-pro/main/install.sh | bash

Windows (PowerShell)

irm https://raw.githubusercontent.com/mohaaa012/web-research-pro/main/install.ps1 | iex

Como plugin de Claude Code

claude plugin marketplace add mohaaa012/web-research-pro
claude plugin install web-research-pro@mohaaa012-plugins

Después, reinicia Claude Code y háblale con normalidad: "Lee este PDF y dame las cifras clave", "Vigila esta página y avísame si baja de 150 €". Para claude.ai, descarga el archivo .skill desde Releases.

Lo que no hace (y por qué)

Ser honesto es parte del diseño.

  • No resuelve CAPTCHAs ni engaña a los sistemas anti-bots. Busca vías legítimas: API pública, RSS, copia archivada u otras fuentes.
  • No se salta muros de pago. Busca la información en fuentes abiertas y avisa de que el original era de pago.
  • No entra en cuentas ajenas. Solo en las tuyas y con tu permiso.
  • No rastrea a lo bestia. Respeta robots.txt, espera entre peticiones y tiene límite de páginas.

Preguntas frecuentes

¿Es una alternativa a WebFetch y WebSearch de Claude?

Sí. WebFetch pasa la página a un modelo pequeño y devuelve su resumen, no ejecuta JavaScript ni puede iniciar sesión. Web Research Pro devuelve el texto completo, usa un navegador real cuando hace falta y busca con región. Para una consulta rápida, WebSearch sigue valiendo; Claude elige la opción más barata en cada caso.

¿Cómo hago que Claude lea páginas hechas con JavaScript?

Instala el skill y pásale la URL a Claude. Si la respuesta normal llega vacía, el skill abre la página en Chromium, espera a que se pinte y devuelve el texto en Markdown.

¿Puede Claude leer un PDF largo entero?

Sí. fetch.py extrae el texto de todas las páginas, con marcas de página para citar. En el benchmark, un PDF de 14 páginas se leyó completo en 1,3 segundos.

¿Sirve para hacer web scraping con Claude Code?

Sí, de forma educada: crawl.py guarda una sección entera de una web como archivos Markdown, respeta robots.txt, espera entre peticiones y quita duplicados. No está pensado para saltarse protecciones.

¿Funciona en claude.ai o Claude Desktop?

Puedes subir el archivo .skill en Settings → Capabilities → Skills, pero allí el entorno puede no tener navegador ni acceso libre a internet. La experiencia completa es en Claude Code.

¿Cuánto cuesta?

Nada. Es open source con licencia MIT. Las claves de búsqueda (Brave, Tavily, SearXNG) son opcionales y todas tienen plan gratuito.
